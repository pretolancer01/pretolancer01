# Olá, sou @pretolancer01 👋

Gosto de criar ferramentas que resolvem problemas do dia a dia. Meus projetos passam por comunicação, áudio e aplicativos para dispositivos que uso. Aqui compartilho o código, o que já funciona e o que ainda estou desenvolvendo.

## Projetos em destaque

### [Orbiter](https://github.com/pretolancer01/orbiter-web)

Protótipo independente de comunicação para navegador e Windows, com comunidades, canais de texto e voz, convites e compartilhamento de tela. Está em desenvolvimento e o README explica como executar e testar o projeto.

### [Voz Local](https://github.com/pretolancer01/voz-local)

Aplicativo para criar narrações com a própria voz no computador. Divide roteiros longos em trechos, permite retomar a geração e verifica a fala antes de exportar o áudio. Os arquivos de referência e os resultados ficam locais.

### [Controle para Google TV e Android TV](https://github.com/pretolancer01/controle-google-tv-android-tv)

Controle remoto para Android, em português do Brasil e sem anúncios. Usa a rede Wi-Fi para encontrar e parear com TVs compatíveis. É uma adaptação de um projeto de código aberto; os créditos e a licença estão no repositório.

## O que estou explorando

- Aplicativos que também sejam úteis fora do ambiente de desenvolvimento.
- Interfaces simples para recursos complexos, como voz, transmissão e integração com dispositivos.
- Documentação clara para que outras pessoas consigam instalar, testar e contribuir.

Se algum projeto foi útil ou você encontrou um problema, abra uma *issue* no repositório correspondente. Sugestões e contribuições são bem-vindas.
